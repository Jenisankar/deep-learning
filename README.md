 Deep Learning Fundamentals

## Project Overview

This project contains introductory Python notes about Deep Learning. It covers the meaning of Deep Learning, its relationship to Artificial Intelligence (AI) and Machine Learning (ML), Artificial Neural Networks (ANNs), neural network categories, real-world applications, and important historical milestones.

The supplied `.py` files are educational notes written as Python comments. They are intended for reading and learning; they do not implement or train a deep-learning model.

## Project Files

| File | Description |
|---|---|
| `What_is_Deep_Learning__ML_VS_DL.py` | Explains Deep Learning, ANN layers, representation learning, why Deep Learning is popular, and the comparison between Machine Learning and Deep Learning. |
| `Types_Application_and_History_of_Deep_Learning.py` | Describes neural network categories, real-world applications, and the evolution of Deep Learning through key milestones. |

## Topics Covered

### 1. What is Deep Learning?

Deep Learning is a subfield of Artificial Intelligence and Machine Learning. It uses multi-layer Artificial Neural Networks to learn patterns and useful representations from data.

### 2. Artificial Neural Networks

An ANN consists of interconnected neurons organized into layers:

- **Input layer:** Receives raw input data.
- **Hidden layers:** Perform computations and extract features.
- **Output layer:** Produces the final prediction or result.
- **Weights:** Represent the strength of connections between neurons.

Multiple hidden layers make a neural network deep.

### 3. Machine Learning vs Deep Learning

The notes compare Machine Learning and Deep Learning in terms of data requirements, hardware requirements, training time, feature selection, and interpretability.

### 4. Categories of Neural Networks

- **MLP:** Multi-Layer Perceptron
- **ANN:** Artificial Neural Network
- **CNN:** Convolutional Neural Network
- **RNN:** Recurrent Neural Network, including LSTM and GRU
- **Autoencoder**
- **GAN:** Generative Adversarial Network

### 5. Applications of Deep Learning

- Computer vision
- Natural Language Processing
- Speech and audio intelligence
- Healthcare and life sciences
- Finance and business analytics
- Robotics and autonomous systems
- Generative AI and creative systems
- Cybersecurity and networks
- Recommendation and search systems

### 6. History of Deep Learning

The notes outline milestones from the mathematical neuron model proposed in 1943 through perceptrons, backpropagation, the 2006 revival of deep learning, GPU acceleration, AlexNet, GANs, Transformers, pretrained language models, and foundation models.

## Requirements

- Python 3 (only if you want to open or run the `.py` files)
- A code editor or IDE, such as Visual Studio Code, PyCharm, or IDLE

No external Python packages are required to read these files.

1. Open the project folder in your preferred code editor.
2. Open either `.py` file.
3. Read the commented notes section by section.

Since the content is written as comments, running the scripts does not train a model or produce a computational result.

## Learning Outcomes

After studying these files, readers should be able to:

- Define Deep Learning and explain its relationship to AI and ML.
- Describe the basic structure of an ANN.
- Distinguish Machine Learning from Deep Learning.
- Identify common neural network architectures.
- Give examples of Deep Learning applications.
- Recognize major milestones in the development of Deep Learning.
